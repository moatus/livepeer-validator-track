# FORENSIC-006: reject these candidates on this exploratory screen

The released RPA frozen encoder and fixed residual/spectrum control do not improve SD1.4/SD1.5 attribution over the original preference baseline. Neither meets the frozen 75% balanced accuracy, >50% conditional cluster lower bound, and <=10% honest known rejection requirements. Stop this screen; no further model search or generation is justified by these results. This is not evidence that all forensic methods fail.

All closed-set measurements include all 36 heldout primary images (18 per class), regardless of rejection. Exactly six original heldout prompt families are used. All 215 usable saved images were encoded; SDXL contributed no fitted statistics, calibration, alpha choice or threshold selection. The safety-excluded SD1.5 image remains excluded. Corpus: 216 attempted, 215 usable; 72 SD1.4, 71 SD1.5, 72 SDXL. Enrollment is train 72 primary images, calibration 35, heldout 36; whole families remain in original 12/6/6 split. Seeds are shared across families, so intervals are conditional, not general population confidence. Original heldout labels were already known; this is exploratory, never fresh confirmation.

RPA base fixes 7 PickScore errors but breaks 11 correct decisions: paired change -11.1 pp, conditional family bootstrap 95% [-16.7,-5.6] pp. The fixed control fixes 7 and breaks 12: -13.9 pp [-27.85,-2.78]. Every comparison uses the exact same 36 primary images and the same 2,000 family draws (seed 904), recomputing sum correct / sum n. No mismatched Qwen subsets are compared. Baseline heads were refit using the frozen original preference scalars; preference inference was not rerun. The recomputed 12 visual values agree with the saved originals to 1e-12.

RPA's untransformed unknown SDXL rejection is 18/18, versus the control's 0/18. This secondary result does not rescue failed close-pair accuracy or honest rejection. SDXL is architecture/native-resolution confounded; moreover the pretrained RPA encoder already saw SDXL as a source class. SDXL is unknown only to this experiment's enrolled head. It cannot establish unknown sibling rejection. Neither representation loses >15 pp under transformations, but both fail the primary thresholds, which is independently sufficient to stop. Resize completely collapses coverage for both; JPEG collapses RPA coverage.

Rejection thresholds use calibration known images only: 95th quantile (higher) of nearest train class-centroid RMS distance after train-only standardization. No threshold is adjusted using SDXL or heldout metrics. This rule rejects 1/35 known calibration images for each head (exact settings in frozen-fits.json). Honest rejection on heldout is a point estimate: 6/36=16.7% RPA and 2/36=5.6% control. The latter does not establish a population <=10% false rejection rate: even an independence-based Wilson 95% interval is about 1.5–18.1%, and prompt clustering further limits precision. Supplementary cluster rejection/coverage intervals are in uncertainty.json. The investigation's acceptance criteria are fixed research thresholds, not standards. Sample precision is inconclusive for certifying low false alarms; failed accuracy is sufficient to reject this bounded lead.
