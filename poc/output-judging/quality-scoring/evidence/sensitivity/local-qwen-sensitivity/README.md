# Offline sensitivity reproduction

Read REPORT.md for results and limitations. Run `bash RUN-COMMANDS.sh` from this directory using the existing, unchanged sibling Qwen numerical environment. No model/inference package is imported, GPU used, or network requested. No install is needed or authorized. Dependencies are Python 3.12, numpy 2.5.4, scipy 1.18.1, scikit-learn 1.9.1, with full original pins in source/requirements.lock.

`analyze.py` independently rederives both frozen arms from source/raw-responses.jsonl, not the reviewer’s recovered exports, and rebuilds all results/CSVs/fits. `verify.py` uses a separate raw parser and centered dual ridge solve, exact discrete comparisons and tolerance-aware continuous comparisons, and independently verifies the ratio bootstrap via explicit multiplicity counts. `write_report.py` renders the report from those outputs; it does no inference.

The source/ snapshots make numerical reproduction independent of original image/model directories. When original directories exist, the verifier additionally checks all start hashes and both terminal manifests, including original baseline score-array provenance; in a standalone bundle those originals are unavailable and corresponding original-integrity counts are zero. They are not inferred from copied manifests. Analysis outputs reproduce identically; verification records whether originals were available. `verification.json` is excluded from the terminal hash manifest because availability-dependent integrity counts differ in a standalone copy.

results.json: complete split class counts, confusions, per-prompt results, paired changes, stability and feature distributions. metrics.csv: all fitted comparisons and intervals. paired.csv: all judge-versus-baseline changes. predictions.csv/json: all train/cal/heldout predictions. coverage.csv: all 215 attempted main cases for each arm, including rejects. response-audit.json: raw text, original status/parsed value, exact extraction, original provenance and derived acceptance. features.csv,distributions.csv,correlations.csv: literal mapped features and descriptive interpretation. fitted-analysis.json: training keys/scaler/coefs, calibration selection keys/alphas; no refit.

Original documents are copied under source/ for context; only analyze.py/verify.py are executable numerical reproduction. Original reports describe historical inference, never an instruction to run it. No images, weights, environments, caches or credentials are in the compact bundle. Never replace original reports or statuses with sensitivity outputs.

Visual indices 0–11 in correlations.csv are red/green/blue means, red/green/blue standard deviations, luminance mean/std, horizontal/vertical mean absolute luminance difference, and channel-range saturation mean/std, respectively. These are existing saved features; none were recalculated through inference.
